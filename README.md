# Susanoo 3D

Scène 3D interactive basée sur le modèle **SASUKE'S SUSANO** de serienreviewer.

## Utilisation

Ouvre `index.html` depuis un serveur local (par exemple l'extension Live Server de VS Code) ou active GitHub Pages dans **Settings → Pages**.

- **WASD** : déplacer le modèle
- **Flèches** : faire pivoter le modèle
- **Glisser avec la souris** : orbiter autour du modèle
- **Molette** : zoomer/dézoomer
